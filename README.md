# About project<br>

This is a test project, the aim of which is to study the basics of working with the Unity Engine and writing code on C#.<br><br>

The project is a top-down shooter which meant to have survival and horror elements.<br><br>

# Implemented mechanics and systems<br>
- dynamic day/night cycle<br>
- grid based player inventory<br>
- diegetic ui<br>
- flexible weapon script. One can setup various weapon types with one script<br>
- weapon equipment system<br>
- IK for some animations<br>
- hunger system<br>
- hydration system<br>
- satiety system<br>
- wakefulness system (not fully emplemented)<br>
- sanity system (in progress)<br>
- max weight capacity and overload system. The amount of weight carried affects on player's stamina and hydration consumption and animation moving speed.<br>
- simple health system<br>
- stamina system<br>
- interactable items (doors, switches, buttons, etc.)<br>
- interactable containers with grid based storage<br>
- simple upgrade system. One can collect money and some resources and spend it on implants<br>
- simple for of war sytem. Player can't see what happens in the next room, until he enters it or looking directly at it without any obstacles<br>
- simple field of view system. Player can't see some items or enemies until he looking at them.<br>
